## Dispositions

| Finding | Resolution |
| --- | --- |
| Process ownership / detached Chromium | Accepted concern; corrected the proposed group-only solution against pdf.py. Graceful unwind and library deadline first, whole-worker-container recycle as hard fallback; other jobs recover through leases. |
| OpenAPI references | Derive a namespaced OpenAPI 3.1 representation from packaged schemas; test reference resolution and document that raw Request metadata does not validate input. |
| Concurrent OOM collateral | Document shared pod failure and bounded retries; size from measurements. No unverified Kubernetes-version claim or oom_score_adj tuning. |
| DB/S3 ownership | Supervisor handles DB/storage; children receive files and an allowlisted environment, with no DB/S3 credentials. |
| HTML versus PDF checks | Document HTML preview success separately from measured PDF layout; cap both outputs and use attachment/nosniff headers. |
| Upload simplification | Bounded spool and single PutObject; early Content-Length check plus actual byte counting; raw bytes and shared reduced DataLimits. |
| Hidden receiving row proposal | Not adopted: prefix scanning is allowed for bounded eventual garbage collection, never for selecting a downloadable result. Keep fewer states and document deadline/grace/repeated scans. |
| Engine version skew | Admission pause/drain/coordinated engine upgrade with compatibility checks; no mixed-engine rolling-update promise. |
| Queue details | FIFO eligibility, partial index, jitter polling, batched heartbeats and original-created-at age. |
| Error handling | Exception-type mapping, safe messages/locations, DependencyError disables claims; no arbitrary exception text in API. |
| Admission limit | Hard local upload semaphore, explicit soft global backlog threshold; 429 for capacity, 503 for dependency failure. |
| Internal docs / versions | Bundle Swagger assets and recommend explicit template versions; no new authentication subsystem. |
| Download cleanup race | Check logical expiry before headers; bounded downloads and delayed physical deletion. |
| Worker probes / identifiers | Worker code gates claims; probes do not substitute for it. Slug/media/archive rules specified. |

These changes are in [the design](../design.md). They are contracts to implement
and test, not evidence that process cleanup or recovery already works.
