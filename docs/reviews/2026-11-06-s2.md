# Template API review

Claude completed a read-only review of S1/S2. The review found one correctness
blocker and three operational concerns, all accepted:

- JSONB reordered keys while the digest covered canonical JSON bytes. Migration
  0003 changes storage to JSON and repairs digests for the unreleased development
  fixtures; 0002 remains immutable. New versions preserve library serialization.
  Retrieval/digest equivalence is covered by the real PostgreSQL lifecycle test.
- Starlette's outer error middleware can log exception messages after returning
  an error response. A pure ASGI boundary now contains unexpected exceptions and
  logs only their class and a generated correlation ID.
- Template validation now shares the bounded upload admission limiter.
- Native API defaults to localhost; containers explicitly opt into all interfaces.

Also accepted: explicit environment-file loading to isolate test runs, DSN-compatible
migration connection creation, and incremental body-limit/TCP timeout tests.

Evidence: Ruff and strict mypy passed; 29 unit and real PostgreSQL/S3/TCP tests passed
at S3. The Linux arm64 image rendered a PDF during S1. These checks do not establish
worker recovery or deployment acceptance, which are separate later slices.
