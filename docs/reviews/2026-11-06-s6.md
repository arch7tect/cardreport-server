# Deployment and final integration reviews

Claude completed the S6 integration review and a narrow final follow-up, both
read-only and exit 0. The follow-up reported no concrete blocker. Raw replies are
preserved under ignored local/; executed checks are in the verification record.

Accepted and implemented:

- Repeated migration Jobs require confirming completion, saving logs, deleting the
  completed Job and applying a new one. Changing a completed Job's image in place
  is not an upgrade procedure.
- Migration pods now have non-root, restricted security settings and resource bounds.
- User docs include stable error codes, shutdown/termination grace relationships,
  fixed namespace, explicit kind prerequisites, proxy/policy/HPA scenarios and
  the distinction between global and per-worker metrics.
- CI preserves failure logs, runs documentation/example validation and avoids a
  redundant image rebuild. Hosted CI remains unexecuted until a remote exists.
- Test-harness teardown includes the app profile, removing only that unique test
  project's API/worker together with its dependencies.
- Worker shutdown cannot wait indefinitely for either maintenance or an active I/O
  future. Normal drain exits zero; exhausted shutdown budget recycles nonzero.

Verification clarifications:

- NetworkPolicy allow/deny/relabel tests passed with kindnet plus policy-only
  kube-router present. No claim is made about which controller alone enforced it.
- The nginx test used incomplete chunked uploads and observed all API intake slots
  occupied before request completion. Opening the probe before the long requests
  were admitted caused a test race; the corrected ordering passed.
- A proxy request timed out during a deployment rollout. Pod readiness alone is
  insufficient; the documented procedure now checks the actual proxy route before
  the smoke. Subsequent compatible rollback and report generation passed. No
  zero-downtime claim is made.
- Production endpoints, multi-node resilience and non-arm64 execution remain outside
  this local acceptance, as documented rather than inferred from manifest validity.
